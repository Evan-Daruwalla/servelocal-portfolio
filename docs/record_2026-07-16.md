### 2. script-src drops 'unsafe-inline'

`frontend/proxy.ts` (Next 16 deprecated the `middleware.ts` filename in favour of
`proxy.ts`) mints a per-request nonce and builds the CSP there. The static CSP
was REMOVED from `next.config.mjs` — two `Content-Security-Policy` headers are
intersected by the browser rather than overridden, so a leftover copy would have
silently broken every page.

This closes the gap ADR-0001 named as the price of localStorage tokens. That
decision leaned on "no XSS sink exists today" (zero `dangerouslySetInnerHTML`) —
an argument about the present that a single future mistake invalidates. CSP is
now an actual backstop instead of a claim.

Deliberately NOT done, both documented in `proxy.ts`: `style-src` keeps
`'unsafe-inline'` (a nonce covers `<style>` elements but never `style="..."`
attributes, which is exactly what React's `style={{...}}` prop compiles to — the
`.v1` pages use it throughout, so removing it breaks the layout of every screen);
and no `'strict-dynamic'` (it makes the browser ignore the Turnstile host
allowlist, and Turnstile is injected by app code as a plain `<script>` tag).

Cost paid: a nonce cannot exist in build-time HTML, so `app/layout.tsx` sets
`dynamic = "force-dynamic"` and **28 routes moved from static prerender to
per-request render**. Cheap here — every page is a client shell that fetches from
the API in the browser, so no server-side data work was being cached — but the
HTML is no longer CDN-cacheable. The 4 metadata routes (icon/OG/robots/sitemap)
stay static; they carry no inline scripts.

Verified in a production build AND through the `output: standalone` Docker image
(where middleware bundling was the actual risk): an inline `<script>` with no
nonce is refused — the console logs "Executing inline script violates the
following Content Security Policy directive" and the injected function never ran;
the same script carrying the served nonce runs; the Turnstile origin still loads;
the nonce differs on every request; the app hydrates and navigates client-side.

data with ZERO console messages.
